# Hi, I'm NeoSpicyPack! 👋

Coffee, code, repeat.

I build interfaces with React, Next.js, and TypeScript — mostly chasing that moment where something just feels right to click, scroll, or tab through. I think a lot about design systems and accessible UI, probably more than is strictly necessary. Lately I've been pulled toward web performance, not just the metrics but the why behind what makes a page feel alive or sluggish, and TailwindCSS plus Vite have become the lens I keep reaching for.

#### What I'm up to

- 🔭 Prototyping a component library with accessibility baked in from day one.
- currently deep in design systems
- happier in a terminal than in an IDE
